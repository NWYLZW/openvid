# 连续镜头运动：已获用户认可的制作经验

2026-09-13，Codex / Openvid 双屏 Duo 演示：用户明确认可平滑后的编辑器效果，并要求把此经验作为关键规则保留。本次认可针对界面预览，未重新验证成片导出。

## 先设计连续路径，再决定在哪里停

- 入场、推近、绕铰链展开、转向左屏，应沿一条连贯路径运动。中间构图点是经过点，不自动意味着停顿。
- 不要对每段都套快速起步、末尾刹停的缓动。本次所有段使用 `[.16,1,.3,1]` 导致每过一个关键帧就重新加速，形成顿挫。
- 不用连续左右甩动制造丰富感。本次展开 yaw 从 `16 → -32 → 30 → -10 → 20` 调整为 `16 → -24 → -6 → 12 → 20`；roll 同时减少反向。
- 只在输入、阅读回复和结果展示时停稳；有意停顿两端保持相同姿态。
- 保留近景与全景的幅度对比：本次最高约 2.15×，全景 0.88×。不要靠缩小所有动作解决不顺的问题。
- 按最终播放时长审查开合。0.75 秒展开难以感知；本次从等待 4× 降至 2×，让 3 秒源时间的开合变成 1.5 秒。

## 本次可复用的插值方法

以源时间为单位，保留少量主要构图点。对 scale/x/y/pitch/yaw/roll/perspective 分通道计算单调三次 Hermite（PCHIP）切线：

1. 相邻区间割线斜率为 `d0, d1`，长度为 `h0, h1`。
2. 若 `d0*d1 <= 0`，该点切线为 0，避免过冲，保持静止区间。
3. 否则采用加权调和平均：`w0=2*h1+h0; w1=h1+2*h0; m=(w0+w1)/(w0/d0+w1/d1)`。
4. 起止切线设为 0；使用标准 Hermite 基函数采样。
5. 本次每段采样 8 份，11 个控制点得到 81 个工程关键帧，采样帧使用线性 easing `[0,0,1,1]`。这是对连续曲线的分段线性近似，不能再给每个采样帧追加 ease-out。

保存粗控制点与采样帧两套数据，后续调整优先改粗控制点并重新采样。所有最终帧仍属于工程 Motion 轨，用户可查看和修改。注意现有参数允许的关键帧数量上限，不无限加密。

本次参数归档在工作区 outputs/codex-camera-smooth-controls.json。该文件是演示配方记录，不是通用产品源码。

## 检查重点

播放看完整连接，而不只是静帧好看。检查经过中间关键帧是否突然刹车、速度突变、缩放与位移脱节、连续反向，以及展开过快。再确认输入框和主要操作区域不被裁掉。
