# 制作流程

从用户目标、现有素材和已有配方开始。先设计足以完成当前视频的流程，不为了未来可能的功能创建目录、脚本或抽象。

创建或调整配方时读取 [配方约定](references/recipe.md)。实际操作阶段按需读取 [openvid-docs](../openvid-docs/SKILL.md)，不要猜测尚未实现的接口。

配方可以包含真正可执行的 Shell、Node.js/CDP、API 脚本，也可以包含 Computer Use 经验。它们是可复用实现，不是要求 AI 永远机械照搬的唯一路径。代码执行结果必须如实判断；修改实现时保留原版与本次差异。

先完成一个真实实例，再依据其中的重复动作、失败和用户反馈演进规范。制作请求需继续到成片；只请求规划或配方时，停在对应交付边界。
